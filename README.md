# Sonic Friends 🦔

A modern-Sonic-styled learning arcade for young fans. 15 voice-guided mini-games,
36 characters, a ring + Chaos Emerald reward system, and zero reading required.

## Games
Meet, Find, Match, Count, Colors (Chaos Emeralds), Shapes, Letters, Who Left?,
Teams (Speed/Fly/Power), Pattern, Big & Small, Chao Song (listen & repeat),
Badnik Bop, Puzzle, Ring Math.

## Rewards
Every correct answer earns rings (saved on the device). Every 30 rings unlocks a
Chaos Emerald. Collect all 7 to go Super Sonic.

## Running it
Plain HTML/CSS/JS — no build step. Open `index.html` or serve the folder
(GitHub Pages: deploy from branch, root folder).

## Optional asset overrides (no code changes needed)
- **Images:** add `img/<character-id>.png` (e.g. `img/sonic.png`) and the game
  uses it instead of the built-in SVG portrait.
- **Voices:** add `sfx/<character-id>.mp3` (e.g. `sfx/tails.mp3`) and that clip
  plays for the character's lines instead of synthesized speech.

Character ids: sonic, tails, knuckles, amy, shadow, rouge, omega, silver, blaze,
marine, cream, big, vector, espio, charmy, mighty, ray, fang, bean, bark, jet,
wave, storm, tikal, chaos, gamma, emerl, shade, honey, tiara, sticks, chip,
metal-sonic, mephiles, infinite, eggman.

Tip: on iPads, tap once after opening to unlock sound, and turn the mute switch off.
