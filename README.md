# Sonic Friends! 🦔

A no-reading-required Sonic character game for little fans, with 36 hand-drawn
character portraits inspired by the Sonic World fan game roster.

## How to play

Open `index.html` in any browser (works great on a tablet — tap targets are big
and everything is spoken out loud). Pick a game from the menu:

- **Meet** — tap any character to hear their name.
- **Find** — a voice asks "Where is Tails?"; tap the right picture. Earn stars!
  It gets a little harder as you go. The speaker button repeats the question.
- **Match** — classic memory game: flip cards to find matching pairs.

No internet, installs, or files needed — sounds and voices are generated by the
browser itself.

Tip: on iPhones/iPads, make sure the silent/mute switch is off to hear the voice.
